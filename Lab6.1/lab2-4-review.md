| Шалгуур | Үр дүн |

| 8+ User Story | Нийт 15 story байна — хангана |
| Хэрэглэгчийн дүр | Хэрэглэгч, жуулчин, оператор, засварчин, админ гэсэн үүргүүд байна |

Удирдамжийн бие даалтын онлайн номын сангийн жишээг энэ репо өөр кейсээр орлуулсан тул багштай
кейсийн зөвшөөрлөө баталгаажуулах шаардлагатай эсэхийг нягтална.

Одоогийн 36 SP backlog-ийн арифметикийг өөрчлөөгүй.

## Lab 4 — Kanban ба тооцоо

- 8 карт, 36 SP, 4 багана, In Progress WIP=3, Review WIP=2 байна.
- Cycle Time нийлбэр **22 өдөр**, дундаж **2.75 өдөр** — шилжилтийн хүснэгттэй таарч байна.

### CFD-г эх өгөгдлөөс дахин тооцсон харьцуулалт

Дүрэм: өдрийн төгсгөлд `start ≤ өдөр < review`, `review ≤ өдөр < done`, `done ≤ өдөр`.
Нэг өдөр Review ба Done болсон US-02 нь тэр өдрийн төгсгөлд Done гэж тооцогдоно.
Эдгээр нь **шалгалтын тооцоо**; Lab 4-ийн хүснэгтийг засварлаагүй.

| Өдөр | Эх файл: To Do / In Progress / Review / Done | Дахин тооцоо | Тайлбар |
|---|---|---|---|
| 0 | 8 / 0 / 0 / 0 | 8 / 0 / 0 / 0 | Таарна |
| 1 | 6 / 2 / 0 / 0 | 6 / 2 / 0 / 0 | Таарна |
| 2 | 5 / 1 / 2 / 1 | **5 / 1 / 1 / 1** | Эх мөрийн нийлбэр 9; нийт 8 карттай зөрнө |
| 3 | 4 / 2 / 1 / 1 | **4 / 2 / 0 / 2** | US-01 Done болсон |
| 4 | 3 / 2 / 1 / 2 | 3 / 2 / 1 / 2 | Таарна |
| 5 | 2 / 2 / 2 / 2 | **2 / 2 / 1 / 3** | US-03 Done болсон |
| 6 | 1 / 2 / 2 / 3 | **1 / 3 / 0 / 4** | US-04 Done, US-07 In Progress |
| 7 | 0 / 2 / 2 / 4 | 0 / 2 / 2 / 4 | Таарна |
| 8 | 0 / 1 / 1 / 6 | 0 / 1 / 1 / 6 | Таарна |
| 9 | 0 / 1 / 1 / 6 | **0 / 0 / 1 / 7** | US-07 Done болсон |
| 10 | 0 / 0 / 0 / 8 | 0 / 0 / 0 / 8 | Таарна |

Дахин тооцоогоор WIP хязгаар зөрчөөгүй: In Progress дээд хэмжээ 3, Review дээд хэмжээ 2.
Гэхдээ Review=2 нь 7-р өдөрт байна; 5–7-р өдөр бүгд 2 байсан гэсэн өгүүлбэр таарахгүй.
US-05–08-ийн Review → Done хугацаа тус бүр **1 өдөр**, 2–3 өдөр биш.
Иймээс Review нь bottleneck болсон гэх тайлбарыг эдгээр өгөгдлөөр батлах боломжгүй.
