# Sprint 1 — Bike Sharing Flutter

## Ажиллуулах

1. Flutter SDK болон Android SDK-гаа суулгана.
2. Өөрийн Firebase project-д Android app бүртгэж, Firebase тохиргоог (`flutterfire configure` эсвэл Android/iOS config файл) холбоно. Auth-ийн Email/Password, Firestore, Functions-ийг идэвхжүүлнэ.
3. `flutter pub get`; `cd functions; npm ci; cd ..`.
4. `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`-ийг Firebase Functions secret-ээр, `STRIPE_PUBLISHABLE_KEY`-ийг ажиллуулах орчинд тохируулна. Төлбөр бодитоор хийгдэхэд Stripe account болон webhook тохиргоо шаардлагатай.
5. `flutter run` эсвэл Windows-д `./run-android.ps1`.
